## Named deficiencies of `.007` — `shortcomings-008` (approved 2026-11-27)

- **R-V1 Self-attested checks.** A check's evidence source is external to the
  flag asserted — self-reported flags corroborated against ground truth
  (process cwd/mount, journal rows, rendered surface), not read at face value.
- **R-U1 Rendered-surface verification gap + standing bar.** Checks exercise
  what the user can reach — rendered surface state and user-path enactment per
  C-UserPathEnactment. Not usable by the user = absence, not enactment.
- **R-F4 Install driven to an outcome.** An install attempt driven to a
  verdict (installed / refused / failed-with-reason) on a named installable
  roster device; "absence" requires an attempted install on an installable
  target, not a skipped one; the join target is an installable device, not
  the gateway.
- **R-A2 Perceivable audio.** Audio scenarios require perceivable evidence —
  a produced artifact or device-confirmed output the owner could hear, not a
  flag asserting it played.
- **R-F5 Device identify/ping.** An identify/ping action on a discovery
  result that signals the device to respond per its capabilities — plus
  materially richer identifying info in results (name resolution,
  vendor/type inference, services seen).
- **R-M1 Metrics in seconds.** Speech-composition latency and time-to-gate
  measured and reported in **seconds** (tenths where results justify) —
  scored on evidence presence and honesty, not normalized.
